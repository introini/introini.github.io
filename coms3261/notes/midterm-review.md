## DFA

#### DFAs:  Given a description of a language in English, write a DFA that accepts that language.

- Example:  Write a DFA to recognize strings of 0s and 1s with an odd number of 1s.
- Example:  Write a DFA to recognize strings of 0s and 1s with a given property, e.g., the presence of a required substring, like 001.

## NDFA

#### Nondeterminism

- Write a NDFA to recognize a given language (described in English), using nondeterminism, if you wish.

## Context-Free Grammars

- Given a language description, write a CFG that generates that language.

    i.  Example:  Write a CFG that recognizes palindromes.

## Pumping Lemma

#### Pumping Lemma for Regular languages

- Know statement of Pumping Lemma
- Understand its proof
- Apply pumping lemma to show some language isn't regular
    
    i.  Example:  Show that $\\{a^jb^j : j > 0\\}# is not regular.
