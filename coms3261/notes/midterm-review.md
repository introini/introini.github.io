## DFA
1.   DFAs:  Given a description of a language in English, write a DFA that accepts that language.

    a.  Example:  Write a DFA to recognize strings of 0s and 1s with an odd number of 1s.
    b.  Example:  Write a DFA to recognize strings of 0s and 1s with a given property, e.g., the presence of a required substring, like 001.

## NDFA
2.  Nondeterminism
    
    a.  Write a NDFA to recognize a given language (described in English), using nondeterminism, if you wish.

## Context-Free Grammars
3.  Context Free Grammars

    a.  Given a language description, write a CFG that generates that language.
    i.  Example:  Write a CFG that recognizes palindromes.

## Pumping Lemma
4.  Pumping Lemma for Regular languages

    a.  Know statement of Pumping Lemma
    b.  Understand its proof
    c.  Apply pumping lemma to show some language isn't regular
    i.  Example:  Show that $\\{a^jb^j : j > 0\\}# is not regular.
