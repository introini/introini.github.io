###Relations 
- Know definitions/vocabulary associated with relations:

Relation
: A *relation* on a set **A** is a relation from **A** and **A**

Equivalence relation
: A relation on a set **A** is called an *Equivalence Relation* if and only if it is **Symmetric, Reflexive,** and **Transitive**

Partially ordered set 
: A relation *R* on a set *S* is called *partial ordering* or *partial ordered* if it is **Antisymmetric, Reflexive,** and **Transitive**. A set $S$ together with a partial ordering $R$ is called a *partially ordered set*, or *poset*, and is denoted by $(S,R)$. Members of $S$ are called *elements* of the poset.
